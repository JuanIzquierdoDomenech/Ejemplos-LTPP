# PythonAlgebraicDataTypes

```bash
# Create an isolated virtual environment in the my_environment folder
python -m venv my_environment

# Activate the environment (from now on pip and python use the environment)
source my_environment/bin/activate

# Install the dependency inside the environment, not system-wide
pip install algebraic-data-types

# Run the program
python main.py

# When finished, exit the virtual environment
deactivate

# Remove the environment to leave no trace
rm -rf my_environment
```
